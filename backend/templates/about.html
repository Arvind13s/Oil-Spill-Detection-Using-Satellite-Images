About This Project

This project uses deep learning with a pre-trained VGG16 model to detect oil spills from satellite images. Oil spills can be devastating to marine environments, and early detection is crucial. Our system allows users to upload satellite images and get instant predictions using our trained AI model.

Developed as part of an academic + real-world use case initiative, this tool combines machine learning with modern web development.
